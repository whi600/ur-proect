# Контракт API первого этапа

Базовый адрес в мобильной конфигурации: `http://<LAN-IP-компьютера>:8000/api/v1`.
Для iPhone это адрес компьютера в общей Wi-Fi сети, а не `localhost`.

| Метод | Маршрут | Назначение |
| --- | --- | --- |
| `GET` | `/health` | Состояние API, режим данных и версия. |
| `GET` | `/documents` | Список карточек; допускает `q` и `limit`. |
| `GET` | `/documents/{document_id}` | Одна карточка с текстом. |
| `GET` | `/search?q=...` | Простой поиск по демонстрационным данным. |
| `POST` | `/assistant/ask` | Интерфейс будущего помощника; сейчас только demo-адаптер. |

Совместимый скрытый маршрут `/documents/search?q=...` сохранён только для
ранних клиентов; новый код использует `/search`.

Пример вопроса:

```json
{
  "question": "Как проверить редакцию?",
  "as_of_date": "2026-09-18",
  "circumstances": "Нужна проверка исторической редакции"
}
```

Ответ помощника имеет `mode: "demo"`, демонстрационный текст, список учебных
карточек и дисклеймер. Ни один маршрут не вызывает внешний ИИ API и не хранит
ключ поставщика на мобильном устройстве.
