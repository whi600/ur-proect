# Архитектура PWA

Проект содержит только веб-приложение и Worker для защищённого вызова ИИ. Expo, Android APK, FastAPI, PostgreSQL и Docker исключены из текущей архитектуры.

```text
браузер / установленная PWA
  ├─ React + TypeScript: интерфейс
  ├─ локальный каталог JSON: быстрый поиск по реквизитам
  ├─ страницы текстов JSON: загрузка при чтении, кеширование service worker
  ├─ localStorage: избранное
  └─ /api/assistant/ask → Cloudflare Worker → Polza AI
```

`vite build` создаёт статический `dist/`; Workbox добавляет service worker. Начальный кеш содержит только оболочку приложения и небольшие ресурсы, но не все тексты. Тексты можно сохранить отдельно кнопкой на главной. Каталог не зависит от ИИ и работает без сети после загрузки PWA.

Worker раздаёт те же статические файлы и обслуживает `/api/*`. Ключ поставщика хранится как секрет Cloudflare и никогда не отправляется в браузер. Ограничитель Worker — 6 запросов в минуту на IP. Это защита от случайной нагрузки, не финансовый лимит.

Будущий юридически корректный помощник потребует: вопрос → уточнение даты и обстоятельств → поиск по полным текстам → выбор редакций на дату → ответ со ссылками на конкретные фрагменты → юридическая оценка качества. Нынешний Worker использует только реквизиты документов, поэтому таких ссылок пока не даёт.
