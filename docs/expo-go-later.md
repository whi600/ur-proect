# Expo Go: памятка для первого запуска

Эта инструкция сохранена для момента, когда вы решите открыть **ПравоОрбиту**
на iPhone. На текущем этапе это бесплатный просмотр разрабатываемого проекта,
а не публикация приложения в App Store. Mac, Xcode и платный Apple Developer
Account для него не нужны.

> Важно: пока запуск на реальном iPhone не проверялся. ИИ-помощник остаётся
> демонстрационным. В нативный пакет добавлен сторонний офлайн-снимок текстов,
> но он заметно маркируется как «не проверено» и не является юридической
> консультацией или гарантированно актуальной редакцией.

## Что уже подготовлено

- Проект: `C:\Users\User\Documents\ChatGPT\консультант плюс ( с ИИ)`.
- Мобильное приложение: `mobile/`.
- Локальный API: `backend/`.
- Нативный офлайн-asset:
  `mobile/assets/legal/ru-core-snapshot-2026-09-25.db` (около 130 МБ,
  37 документов). Он требуется для чтения снимка без сети и не хранится в
  Git; команда воспроизведения есть в [README](../README.md#локальный-снимок-текстов-для-expo-go).
- В `mobile/.env` уже сохранены два несекретных адреса:
  - `EXPO_PUBLIC_API_BASE_URL_WEB` — для браузера на ноутбуке (`127.0.0.1`);
  - `EXPO_PUBLIC_API_BASE_URL` — для iPhone в той же Wi-Fi-сети (текущий LAN-IP
    ноутбука: `192.168.0.106`).

LAN-IP может измениться после переподключения к Wi-Fi. Не добавляйте в
`mobile/.env` пароли, ключи ИИ или строку подключения PostgreSQL: всё с
`EXPO_PUBLIC_` попадает в мобильную сборку.

## Один раз на iPhone

1. Установите **Expo Go** из App Store.
2. Создайте или войдите в бесплатный Expo-аккаунт в Expo Go.
3. Убедитесь, что iPhone и ноутбук подключены к одной доверенной домашней или
   рабочей Wi-Fi-сети. Для Expo SDK 57 нужна актуальная App Store-версия Expo
   Go и iOS 16.4 или новее.

Официальные справки: [Expo Go](https://docs.expo.dev/get-started/set-up-your-environment/),
[вход для SDK 57](https://expo.dev/changelog/expo-go-57-login).

## Запуск на ноутбуке

Для чтения локального снимка нужен только Expo. API нужен отдельно, если
хотите проверить серверные эндпоинты: текстовый снимок от него не зависит.

Сначала убедитесь, что локальный пакет на месте:

```powershell
Test-Path 'C:\Users\User\Documents\ChatGPT\консультант плюс ( с ИИ)\mobile\assets\legal\ru-core-snapshot-2026-09-25.db'
```

Ожидается `True`.

Откройте **два отдельных** окна PowerShell, если запускаете также API.

### Окно 1 — API

```powershell
Set-Location 'C:\Users\User\Documents\ChatGPT\консультант плюс ( с ИИ)\backend'
.\.venv\Scripts\python.exe -m uvicorn app.main:app --host 0.0.0.0 --port 8000 --reload
```

Проверьте в третьем окне PowerShell, что API отвечает:

```powershell
Invoke-RestMethod 'http://127.0.0.1:8000/api/v1/health'
```

Ожидаемый признак: `status` равен `ok`, а `data_mode` равен `demo`.

### Окно 2 — Expo для iPhone

```powershell
Set-Location 'C:\Users\User\Documents\ChatGPT\консультант плюс ( с ИИ)\mobile'
npx expo login
npm run start:lan
```

Команда `npx expo login` попросит войти в ваш Expo-аккаунт. Это нормально и
нужно выполнить самостоятельно. После запуска Expo покажет QR-код. Откройте
Expo Go на iPhone, войдите в **тот же** Expo-аккаунт и отсканируйте QR-код.
На первом запуске дождитесь экрана «Подготавливаем офлайн-каталог»: Expo Go
один раз копирует SQLite-пакет во внутреннее хранилище приложения.

## Если Wi-Fi-адрес ноутбука изменился

1. В PowerShell выполните:

   ```powershell
   ipconfig
   ```

2. Найдите IPv4-адрес активного Wi-Fi-адаптера, например `192.168.1.25`.
3. Откройте `mobile/.env` и замените только правую часть этой строки:

   ```text
   EXPO_PUBLIC_API_BASE_URL=http://192.168.1.25:8000/api/v1
   ```

4. Остановите Expo сочетанием `Ctrl+C` и снова выполните `npm run start:lan`.

`localhost` и `127.0.0.1` здесь использовать нельзя: на iPhone они указывают
на сам телефон, а не на ноутбук.

## Если приложение показывает «API недоступен»

Сначала проверьте, что API из предыдущего раздела запущен. Затем убедитесь,
что iPhone и ноутбук в одной сети. Не отключайте брандмауэр целиком.

На этом компьютере текущая Wi-Fi-сеть помечена как публичная, поэтому доступ
телефона к API намеренно не открывался. Когда сеть станет доверенной, сначала
измените её профиль Windows на **Private** вручную. Затем в PowerShell,
запущенном от имени администратора, добавьте только узкое правило для API:

```powershell
New-NetFirewallRule -DisplayName 'ПравоОрбита API (Private)' `
  -Direction Inbound -Action Allow -Protocol TCP -LocalPort 8000 -Profile Private
```

Правило не открывает PostgreSQL: база при её будущем запуске будет доступна
только с `127.0.0.1` на самом ноутбуке.

## Что означают команды Expo

| Команда | Для чего |
| --- | --- |
| `npm run web` | Открыть приложение в браузере ноутбука. |
| `npm run start:lan` | Показать QR-код для Expo Go в общей Wi-Fi-сети. |
| `npm run start:tunnel` | Запустить туннель только для загрузки приложения Expo. Локальный FastAPI через него сам не становится доступен iPhone. |
| `Ctrl+C` | Остановить Expo или API в соответствующем окне PowerShell. |

Не создавайте публичный туннель к API без отдельного решения по безопасности.
Если QR-код не открывается через LAN, можно временно попробовать
`npm run start:tunnel`, но интерфейс может перейти в локальный демонстрационный
режим, пока API недоступен телефону.

Для офлайн-снимка это не препятствие: после первого импорта его каталог,
поиск и уже открытые фрагменты не требуют FastAPI. Метка «СНИМОК · НЕ
ПРОВЕРЕНО» означает, что текст нельзя использовать как юридически
верифицированную редакцию.

## Быстрый локальный просмотр без телефона

```powershell
# Окно 1
Set-Location 'C:\Users\User\Documents\ChatGPT\консультант плюс ( с ИИ)\backend'
.\.venv\Scripts\python.exe -m uvicorn app.main:app --host 0.0.0.0 --port 8000 --reload

# Окно 2
Set-Location 'C:\Users\User\Documents\ChatGPT\консультант плюс ( с ИИ)\mobile'
npm run web
```

Затем откройте `http://localhost:8081`. Этот сценарий использует отдельный
локальный адрес API и не меняет настройку, нужную для будущего iPhone.
