# Подключение ИИ через Cloudflare Worker

Приложение использует один опубликованный Worker для PWA и вызова модели.
Ключ Polza AI хранится **только в секретах Worker**; в Git, `mobile/.env`,
`EXPO_PUBLIC_*` и код приложения его записывать нельзя. До добавления секретов
платные вызовы выключены, а интерфейс показывает ошибку настройки, не
выдавая демонстрационный ответ за работу модели.

## Выбранная модель и пределы этого этапа

Стартовая модель — `deepseek/deepseek-v4-flash` через Polza AI. На странице
Polza на 29.09.2026 указаны 8,86 ₽ за 1 млн входных и 17,73 ₽ за 1 млн
выходных токенов. Это ориентир, а не гарантия будущей цены или качества:
[карточка модели](https://polza.ai/models/deepseek/deepseek-v4-flash).
Для сравнения можно испытать `google/gemini-2.5-flash-lite` и
`openai/gpt-5-mini` на одинаковом наборе правовых вопросов, но не включать
более дорогую модель автоматически. Один ключ Polza допускает смену модели
на стороне Worker без обновления PWA.

Важно различать три задачи:

1. Поиск для ИИ сейчас выбирает **карточки с реквизитами**. Тексты статей есть
   в PWA для чтения, но Worker пока не использует их как контекст. Проверенных
   редакций нет.
2. Модель делает предварительный разбор вопроса и предлагает, какие документы
   проверить. Она не должна придумывать номера статей и цитаты.
3. Поиск в интернете **ещё не подключён**. Для него нужен отдельный поисковый
   источник/инструмент с проверяемыми URL, датами и контролем расходов.

Нативный SQLite-снимок не загружается в Cloudflare. Отдельные веб-страницы
текстов публикуются как статические файлы, но этот Worker пока их не читает.
Тексты не прошли юридическую проверку.

## Как включить после собственного решения об оплате

1. Создайте ключ в своём аккаунте Polza AI. Не присылайте его в чат и не
   публикуйте в GitHub. Сначала проверьте тариф и установите для себя
   приемлемый бюджет использования.
2. Откройте Cloudflare → **Workers & Pages** → **ur-proect** → **Settings** →
   **Variables and Secrets** → **Add**. Выберите тип **Secret** и добавьте
   `POLZA_API_KEY` со значением ключа Polza.
3. Примените изменение кнопкой **Deploy**. Откройте `/assistant` в PWA и
   задайте пробный вопрос **без персональных данных**. Модель
   `deepseek/deepseek-v4-flash` выбрана по умолчанию.

Приложение отправляет вопрос в тот же Worker по HTTPS без кода доступа;
Worker ограничивает обращения до 6 запросов в минуту с одного IP, выбирает до пяти
карточек каталога и обращается к Polza AI. Ответ модели помечен как
предварительный; связанные карточки не являются ссылками на конкретные статьи.
Публичный доступ означает, что любой посетитель может расходовать баланс
вашего аккаунта Polza. Ограничитель запросов на один IP не является общим
денежным лимитом и не защищает от распределённой нагрузки. Установите лимит
расходов у поставщика, если он доступен, и следите за использованием.

Для Android интернет требуется только для ИИ: локальная библиотека и
избранное продолжают работать отдельно. Если адрес Worker изменится, укажите
его публичный `/api/assistant/ask` в `mobile/.env` как
`EXPO_PUBLIC_ASSISTANT_API_URL`; ключ Polza туда не помещайте.

## Локальная проверка без платных запросов

```powershell
Set-Location 'C:\Users\User\Documents\ChatGPT\консультант плюс ( с ИИ)'
npm run test:worker
npm run build
npm run verify:cloudflare
```

Реальная стоимость и качество для российских правовых задач не проверены до
появления ключа и контрольного набора вопросов. Перед публичным применением
нужны источник актуальных текстов, поиск по фрагментам с редакцией на дату,
ссылки на официальные публикации и юридическая проверка ответов.
