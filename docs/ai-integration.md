# ИИ-помощник в PWA

Браузер отправляет вопрос на `/api/assistant/ask` того же домена. Cloudflare Worker проверяет длину запроса, ограничивает частоту по IP, выбирает до пяти карточек каталога и вызывает Polza AI. Поставщик по умолчанию: `deepseek/deepseek-v4-flash`. Ответ помечен как предварительный учебный разбор.

Ключ `POLZA_API_KEY` должен быть создан в аккаунте владельца и сохранён только как **Secret** в настройках Worker. Не кладите ключ в Git, файлы `.env`, JavaScript, переменные `VITE_*` или настройки браузера. Адрес сайта не является секретом.

Статус конфигурации доступен по `GET /api/assistant/status`. Поле `configured: true` подтверждает только наличие секрета и ограничителя, **не правильность ключа и не успешный ответ модели**. Поле `revision` помогает понять, опубликован ли новый Worker. Ошибки поставщика возвращаются без текста его ответа и без секрета.

Пока нет поиска в интернете и по текстам статей. Карточки, приложенные к ответу, не подтверждают конкретную норму или редакцию. Для правового применения нужен официальный текст на дату события и независимая юридическая проверка. Публичный доступ может расходовать баланс владельца; установите лимит расходов у поставщика, если доступен, и наблюдайте за использованием.

Локально код Worker проверяется `npm test`; опубликованный вызов поставщика проверяется отдельно после публикации. Локальная PWA на Vite без Worker не имеет доступа к платной модели.
