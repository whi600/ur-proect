# Открытие каркаса на iPhone

## Что потребуется

- iPhone с поддерживаемой текущей Expo Go версией iOS;
- бесплатное приложение **Expo Go** из App Store;
- бесплатный Expo-аккаунт: он должен быть одинаковым в Expo Go и в терминале
  Windows для актуального iOS Expo Go;
- iPhone и компьютер в одной частной Wi-Fi сети.
- локальный файл `mobile/assets/legal/ru-core-snapshot-2026-09-25.db`, если
  требуется проверить офлайн-снимок текстов. Он не попадает в Git и имеет
  статус «не проверено».

## Подготовка API (нужна только для серверной проверки)

Офлайн-снимок текста после первого импорта не требует FastAPI. Этот раздел
нужен для проверки API и будущих сетевых функций, но отсутствие API не должно
мешать чтению уже встроенных фрагментов в Expo Go.

1. Узнайте IPv4-адрес компьютера в нужной Wi-Fi сети:

   ```powershell
   Get-NetIPAddress -AddressFamily IPv4 |
     Where-Object { $_.IPAddress -notlike '127.*' -and $_.PrefixOrigin -ne 'WellKnown' } |
     Format-Table IPAddress,InterfaceAlias
   ```

2. В `mobile/.env` укажите адрес, например:

   ```dotenv
   EXPO_PUBLIC_API_BASE_URL=http://192.168.1.25:8000/api/v1
   ```

   Здесь нельзя использовать `localhost`: на iPhone он означает сам телефон.
   После изменения `.env` перезапустите Expo.

3. В окне PowerShell запустите API на всех интерфейсах:

   ```powershell
   Set-Location <путь-к-проекту>\backend
   .\.venv\Scripts\python.exe -m uvicorn app.main:app --host 0.0.0.0 --port 8000 --reload
   ```

4. Если Windows спросит о сети, разрешите доступ только в профиле **Private**.
   Если запроса нет и телефон не видит API, создайте узкое правило (PowerShell
   от имени администратора), не отключая брандмауэр:

   ```powershell
   New-NetFirewallRule -DisplayName 'ПравоОрбита API (Private)' `
     -Direction Inbound -Action Allow -Protocol TCP -LocalPort 8000 -Profile Private
   ```

   Не добавляйте правило для Public и не публикуйте порт PostgreSQL.

## Запуск Expo Go

1. Откройте Expo Go на iPhone и войдите в Expo-аккаунт.
2. В PowerShell на компьютере выполните:

   ```powershell
   Set-Location <путь-к-проекту>\mobile
   npx expo login
   npm run start:lan
   ```

3. Сканируйте QR-код камерой iPhone и выберите открыть в Expo Go. На первом
   старте дождитесь экрана «Подготавливаем офлайн-каталог»: большой SQLite-
   пакет один раз копируется во внутреннее хранилище Expo Go.
4. Выполните поиск Конституции или кодекса и проверьте, что карточка текста
   имеет метку «СНИМОК · НЕ ПРОВЕРЕНО». Если API запущен, его индикатор должен
   показать доступность; если нет — офлайн-снимок всё равно не должен исчезать.
   Экран ИИ-помощника остаётся демонстрационным.

Если LAN-подключение Expo не проходит из-за правил Wi-Fi, можно проверить
только доставку приложения через `npm run start:tunnel`. Это **не** делает
локальный FastAPI доступным телефону: для API всё равно нужны общая Wi-Fi сеть
или другой согласованный безопасный способ, который на этом этапе не создаётся.

Физическое открытие на вашем iPhone требует ваших действий. До вашего
подтверждения оно считается подготовленным, но не проверенным на устройстве.
